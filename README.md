
# Simple Interest Calculator

## Project Overview
The Simple Interest Calculator is a beginner-friendly project that calculates simple interest using the principal amount, annual rate of interest, and time period.

## Project Name
Simple Interest Calculator

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal amount
- Annual rate of interest
- Time period in years

## Technology
- Bash scripting
- Git and GitHub

## Purpose
This project demonstrates basic input handling, arithmetic calculations, and version control using Git and GitHub.
