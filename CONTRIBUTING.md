# Contributing Guidelines

## Welcome
All contributions to the Simple Interest Calculator project are welcome.

## How to Contribute
- Suggest new features and improvements.
- Report bugs and errors.
- Fix bugs and submit improvements.
- Improve project documentation.
- Share ideas to make the project better.

## Bug Reports
When reporting a bug, clearly describe the issue and provide steps to reproduce it.

## Bug Fixes
Ensure that your changes address the reported issue and do not introduce new problems.

## Documentation Improvements
You can improve README files, instructions, and other project documentation.

## Enhancements
Suggestions that improve usability, functionality, or code quality are encouraged.

## Ideas
Feel free to suggest new features and improvements for future versions.

## Submitting Changes
1. Fork the repository.
2. Create a new branch for your changes.
3. Make and test your changes.
4. Commit your changes with a descriptive message.
5. Submit a pull request explaining your contribution.

Thank you for contributing!
